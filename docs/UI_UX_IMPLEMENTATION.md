# UI/UX implementation — GHI 2.3.0

The active UI uses a single clean dark/navy Compose shell with five destinations: Discover, IP / Domain, Response, Payloads and Settings.

The Response screen preserves the supplied HTTP Custom reference language: compact dark cards, blue controls, green/amber/red status states, progressive result animation, CDN filter/status information, copy actions and DNS diagnostics.

No History, Search, Graph, Bookmarks or redundant duplicate intelligence menus are exposed.
