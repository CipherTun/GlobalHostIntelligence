# GHI 4.1.0 — Intelligence Platform Upgrade

- Chrome Android 153 reduced UA is the default browser identity across network analysis and request generation.
- Gemini-inspired local spectrum spark with contextual, low-contrast work messages and a short pre-spark phase.
- Real HTTP/1.1 request builder with CRLF framing, UTF-8 Content-Length validation, cURL export and Fetch export.
- Bounded Web Surface Inspector for standard discovery files, title/canonical metadata and same-origin links.
- Investigation and GHI Agent include Web Surface intelligence.
- Loading indicators cover discovery, subdomains, IP/domain resolution, response checking, TLS, DNS, certificates, investigation, agent and web-surface operations.
- Discovery/subdomain limits are raised to 5000 while retaining bounded source concurrency.
- Production ads, release signing, R8-disabled release builds, ARM32/ARM64 AAR packaging and existing Go build caching remain preserved.
