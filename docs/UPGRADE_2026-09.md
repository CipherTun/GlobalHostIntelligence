# GlobalHostIntelligence 2.3.0 — focused application upgrade

This revision intentionally removes redundant workspaces and concentrates the application on the five requested tools: Discover, IP / Domain, Response, Payloads and Settings.

Discovery and validation are parallelized, country selection is worldwide through ISO country codes, public/free source adapters are selectable, and validation remains restricted to HTTP/HTTPS 2xx–3xx.
