# Code of Conduct

## Our standard

Participants in the GlobalHostIntelligence project are expected to:

- Be respectful and constructive.
- Assume good faith.
- Focus criticism on ideas, code and technical decisions.
- Avoid harassment, threats, discrimination and personal attacks.
- Respect privacy and do not publish another person's private information.

## Maintainer response

Project maintainers may remove comments, close discussions or restrict participation when behavior violates this standard.

## Security reports

Do not use public discussions or issues for undisclosed security vulnerabilities. Follow `SECURITY.md`.
