# Global Host Intelligence 2.4.0

Focused navigation: Discover, IP / Domain, Response, Payloads, Export, Discovery Sources, Settings.
No History, Search, Graph, Bookmarks, or other redundant feature areas are included.
No "last used discovery sources" feature is stored or displayed; source selection remains an explicit Discovery Sources menu.

Added public/passive discovery adapters: Subdomain API, Rapid7 Sonar-derived endpoint, Riddler, JLDC/Anubis and Sublist3r API.
BufferOver and RedHuntLabs were deliberately not added because current 2026 research reports them unreliable/defunct for free use.
