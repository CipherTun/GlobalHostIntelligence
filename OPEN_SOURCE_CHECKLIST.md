## GitHub settings still requiring the repository owner

1. Set the repository description using `docs/PROJECT_METADATA.md`.
2. Add the recommended topics.
3. Configure the repository social preview image.
4. Review the repository's Community Standards checklist.
5. Enable appropriate security features for the public repository.
6. Create a GitHub Release after a verified APK build.
